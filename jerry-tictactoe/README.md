# Jerry’s Games: Tic Tac Toe

A clean, dark Tic Tac Toe game with 2-player and vs-Computer modes.
When the computer wins, you hear the "Fahhh" sound.

**Created:** 21 Nov 2026  |  **Version:** 1.0.0  |  **By:** Jerry Designs
(Programmer, Website Designer, Graphics Designer)

## Files
- `index.html`: the whole game
- `assets/fahhh.mp3`: the computer-wins sound
- `manifest.webmanifest`, `sw.js`, `icon-*.png`: make it installable and work offline

## Edit your details
Open `index.html` and change the `CONFIG` block near the bottom
(name, date, roles, skills, and your GitHub / email / website links).

## Run it locally (VS Code)
1. Open this folder in VS Code.
2. Install the **Live Server** extension, right-click `index.html`, choose **Open with Live Server**.

## Put it on GitHub (free hosting)
1. Create a new repository on github.com and upload all the files in this folder.
2. Repo **Settings > Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. After a minute your game is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

## Make an Android APK (free, no Play Store)
1. Finish the GitHub Pages step above so the game has a live link.
2. Go to **pwabuilder.com**, paste your link, and choose **Package for stores > Android**.
3. Download the package. It includes an `.apk` you can install directly and a signing key.
   **Keep the signing key safe** and never upload it to GitHub.
4. To share the APK on GitHub: repo **Releases > Draft a new release > attach the `.apk`**.

Users may need to allow "install from unknown sources" on their phone to install an APK outside the Play Store.
